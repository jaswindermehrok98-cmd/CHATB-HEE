# UNPLUG LABS® OFFLINE OS

**USE IT. DON'T LET IT USE YOU.**

OFFLINE OS is a native Android launcher designed around intentional phone use.

## For people who just want the app

Go to the official download page:

**https://unpluglabs-offlineos.vercel.app/download**

On Android:

1. Tap **Download for Android**.
2. Open the downloaded APK.
3. Allow Android to install it from that source when prompted.
4. Open OFFLINE OS and follow the setup.
5. Choose OFFLINE OS as your Home app when Android asks.

You do **not** need to understand GitHub to install OFFLINE OS.

## For developers

This repository contains the native Android source and the automated APK build workflow.

Application package:
com.unpluglabs.offlineos

Android baseline:
7.0+ (API 24)

Current release channel:
Preview

## Repository structure

- app/ — native Android application
- gradle/ — Gradle configuration
- .github/workflows/ — APK build and release automation
